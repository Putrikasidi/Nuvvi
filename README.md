# Nuvvi

## Apa itu Nuvvi

Nuvvi adalah website aplikasi kesehatan untuk membantu user mengonsumsi makanan yang lebih bergizi dan hidup lebih seha melalui scan/pencatatan makanan & nutrisi, pemantauan aktivitas olahraga, pengaturan jadwal & pengingat harian plus kondisi/obat, serta komunitas dan grup untuk saling berbagi. Website ini dibuat dengan HTML + Tailwind CSS + JavaScript.


## Cara menjalankan

```
cd Nuvvi
python -m http.server 8080
```
Localhost:  `http://localhost:8080`.
